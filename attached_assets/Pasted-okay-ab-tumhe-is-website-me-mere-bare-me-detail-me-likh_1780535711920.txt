AEROGRAB (Inside Hevi Explorer)
What: Gesture-controlled P2P file transfer

How:

✊ Closed Fist = "I'm grabbing this file" (sender)
✋ Open Palm = "I'll catch it" (receiver)
The Flow:

Person A makes fist gesture on camera
Google MediaPipe AI (100% on-device) detects it
Server broadcasts wake signal to all nearby devices
Person B gets notification: "Person A is sending file.jpg"
Person B opens palm on their camera
WebRTC P2P connection opens → file travels directly device-to-device
Server NEVER touches the file (pure relay only)
File auto-opens in Hevi on Person B's phone
Tech Behind AeroGrab:
